# Workbench：工程契约

## 架构取舍

Windows x64、C++17/DirectWrite 核心 + .NET 10 WPF 薄界面。性能敏感的系统枚举、字体元数据、匹配、字面选择、shaping、像素采样全在原生层。WPF 负责输入法、可访问性、DPI、交互和虚拟化，不负责按家族名字重新解析出另一个“相似字体”。工作台和核心不引用旧 WPF 工程、第三方 NuGet、Python、Skia 或私有 Apple 资源。批量操作通过独立管理库复用旧引擎经过测试的事务及 Windows 检查；旧 EXE 仅作为老日志恢复的可选兼容入口。

| 模块 | 负责 | 明确不做 |
|---|---|---|
| `native/catalog.cpp`、`search.*` | 从 Windows 本地 typographic collection 或明确选择的私有文件建立不可变目录；按界面语言显示，英文/原始名作项目引用键，本地化名作搜索别名；稳定的精确 → 前缀 → 包含排序 | 不递归扫磁盘，不下载字体，不猜 PS 名前缀，不在每次输入时重读 name 表 |
| `native/selection.cpp`、`render.cpp` | 选中时才访问样式、路径、TTC 索引、glyph count、轴和字符映射。对指定文件/索引/模拟样式和轴构造单面集合；关闭系统字体回退，并验证实际绘制 run 的 face | 不替损坏字体改表，不用其他字体假装预览成功；不宣称支持彩色层或覆盖即 shaping 成功 |
| `native/api.h`、`desktop/Native.cs` | 窄且版本化的 x64 UTF-16 C ABI、HRESULT、RAII 和 SafeHandle，托管层在所有者仍存活时复制字符串 | 无跨边界 C++ 异常、无传给 UI 的裸 COM 指针、无 DLL 跨堆释放 |
| `desktop/FontCatalog.cs`、`LatestWork.cs` | 不可变目录、按代更新 UI。目录、检索、样式、字面、绘制各自最多一个执行中作业；旧请求可取消，旧结果不可发布；过期句柄显式释放 | 不阻塞输入做扫描，不全库生成缩略图，不为每个样式建 WPF 控件 |
| `desktop/MainWindow*` | 已安装库 / 文件预览 / 项目清单导航、虚拟列表、排字标本、状态及错误、键盘焦点 | 无假字体/假统计；不直接打开注册表、保险库或删除文件 |
| `session/` | 显式同意后临时添加 GDI 字体引用、固定源、会话内成对释放。UI 仅允许操作明确选择的私有文件；关闭有未释放项时保留窗口供重试 | 不持久注册、不复制文件、不把其他进程或上次崩溃留下的引用当作自己的；测试不调用真实 GDI 写入 |
| `collections/` | 有上限、版本化的 JSON，按 revision 做乐观并发控制；写前锁定并重新读取，同目录刷盘及原子替换 | 不存字体二进制，损坏文件和未来 schema 不盲目覆盖；不靠扫描家族顺序作持久 ID |

## 显式上限与失败语义

- 目录最多 100,000 家族，单家族至多 65,536 样式；每家族最多取 64 个别名，单名称至多 2048 UTF-16 单元。系统目录里孤立的不可读家族有可见跳过计数。系统 API 整体失败没有演示库回退。完整刷新失败时保留原有可用快照。
- 搜索最长 1024 个 UTF-16 单元、64 个词；按不变区域折叠。相同排序等级保留原来的顺序。不同家族出现相同持久键时仍可浏览，但不允许错误收藏进同一项。
- 私有打开只接受显式规范盘符路径的 SFNT 文件；不展开目录或网络路径，不以 WPF 安装名替代原文件。每次至多 128 个文件、单文件 1 GiB、总量 4 GiB、单集合 4096 面；坏输入整批报错而非假报“全部导入”。
- 标本只在选中项、文本、字号、DPI、轴或视口变化时绘制。原生层最长 2048 UTF-16 单元、每边不超过 4096px 且不超过 4M 像素；超限、非有限数和越界轴值拒绝。预览按实际可见窗口裁剪。`fb_map` 的 GID=0 表示该 face 无直接映射；UI 对不同的非空白、非控制字符计数，忽略变体选择符。
- 系统扫描和私有扫描是两种来源。Windows 返回的 **样式数** 可含命名实例，与旧版“磁盘文件内 face 数”不是同一指标。搜索针对家族及别名，不假称可搜索未读取的所有样式元数据。

## 数据、操作和回滚

项目清单只写 `%LOCALAPPDATA%/FontBook.Workbench/shelves.v1.json`（首次实际创建/修改清单时）。渲染和目录只用内存；回到已安装库或关窗会释放私有集合。发行脚本只写本仓被忽略的 `artifacts/` 及项目的 `bin/obj`。

主窗批量操作按确认的物理家族/文件执行。新域 `%LOCALAPPDATA%/FontBook.Workbench/management/ops` 保存可验证日志，`management/vault` 保存可恢复字体。禁止混用、移动或清理旧 `%LOCALAPPDATA%/FontBook/ops`、`vault`；旧记录在主应用只读，旧版兼容入口独立处理。

回滚程序版本可以关闭工作台后回到之前的发行目录；这不会回滚已确认的系统字体操作。请先在本版本验证需要的恢复记录，保留全部日志和备份。不同程序版本和文件来源不得视为相互可替代的恢复授权。

**会话试用边界：** 已安装库的浏览、搜索和私有预览从不隐式激活。试用只接受本地固定卷上的规范 SFNT 路径、单链接且不超过 128 MiB；Windows/用户安装目录、脱机和重解析路径拒绝。进程保持只读文件及父目录句柄，原登记成功后才记一次可释放引用；系统拒绝释放则保留记录。修改系统字体表须逐次确认，通知不等于其他应用已刷新。异常退出不能回放未经证实的 GDI 引用；如字体仍在会话中可见，可能需重启 Windows。没有真实恢复演练时不把这些承诺写成跨应用验收结果。

清单文件用于当前 Windows 用户的本地配置；并发测试验证同一登录会话的两个进程。跨登录会话共享清单文件、网络盘和云同步目录不是受支持的存储方式。

## 字形与覆盖诊断（ABI 2）

只有打开字形窗才会为选择的字面建立 Unicode 到 GID 的反向索引。索引按 1024 个 Unicode 标量分块检查取消。Windows 提供的范围表负责加速，如果范围信息不可靠，使用同一字面的 `GetGlyphIndices` 遍历有效标量。`post` 名称来自同一字面的表。每页渲染 48 个轮廓，别名每组最多 64 个。跳转到码点时在有序别名里二分定位。第一次选择、切换样式和关闭窗口都由各自的取消操作管理，返回的本机名称在句柄持有期间复制。

`fb_render_glyph` 直接绘制一个 GID，沿用标本的轴值和灰度合成。主窗口的覆盖分析单独计算文本中的标量、出现次数、缺失、忽略项和无效 UTF-16。严格区分控制符、格式符和实际可复制字符。Unicode 映射和 `post` 名称分别展示，复杂脚本的视觉结果以实际排版为准。

## 桌面管理、外观与直接排版（ABI 3）

- `management/` 将旧版单家族签名事务封装为两阶段批量计划。库存通过 `IDWriteFontFaceReference` 读物理路径和 index，不为全库创建真实字面；只有所选文件才读磁盘/注册项取证。无法确定完整归属时拒绝写入。预检可逐家族取消，按下确认后重新核对证据；每项事务独立留存结果和恢复依据。
- `VirtualizingTilePanel` 和 `WorkbenchFamilyPreview` 只为当前视口附近的家族分配容器/标本位图，有界并发、取消和按图像字节淘汰缓存。紧凑列表、网格、样本共享同一个 ListBox 选区，不为换视图重扫字体。
- `native/editor_layout.h` 暴露拥有自己字体资源的排版快照。鼠标、选区、插入点使用文档 DIP；物理位图按 DPI 和当前滚动量绘制。WPF 文本宿主保留输入、IME 和撤销，灰度抗锯齿的图像按主题前景着色。只有明确指定的 OpenType tag 交给 `IDWriteTypography`。
- `native/font_details.*` 从当前 face 复制名称、许可、轮廓、度量和可选表。损坏/缺失的可选表有自己的状态。非模态详情窗明确是打开时的快照，不会因主选区变化而展示另一个同名字面。主题与高级文字 API 的微软资料见 `WINDOWS-UI.md`。

生产卸载只处理系统或当前用户标准字体安装目录的直接子文件。其他设计资源库的注册引用可以审查停用，但不从库中删除原件。一次停用/卸载的可执行家族数达到 10 时，必须在预检中输入准确数量；单击或按 Enter 不会直接执行。
